# 测试范围

Node单元测试检查学习状态、幂等奖励、草稿、版本、计时、迁移和备份。
Worker接口测试使用内存D1模拟，不能替代Cloudflare真实部署测试。
Chromium测试通过本地HTTP服务检查手机和平板页面、输入和按钮交互、保存、PIN、导出、恢复、奖励和限时。
Android模拟器测试检查原生安全来源、WebCrypto、安装启动、Activity重建、真实WebView内学习流程和原生存储。
测试报告与截图来自GitHub Actions。只有成功运行的结果才能称通过。
尚没有用户实际手机或平板、厂商语音服务、学校教材、真实AI调用质量测试。
构建/测试通过不等于长期教育效果保证。
