# Word Pet 1.5 星语岛：学习模式与宠物模式重构

## 产品取舍
参考多邻国的路径式学习、短练习、即时反馈、间隔复习；儿童体验更接近Duolingo ABC的分步引导。所有角色、矢量插画、布局细节、题目和文案均为Word Pet原创，不使用多邻国品牌或课程素材。

不采用扣生命、排行榜、断签惩罚、随机抽奖、广告或付费道具。不把学习时长、星星和选择题正确率伪装成作文能力评分。

## 每天约15分钟
学习约13分钟：旧知识热身 / 新词辨析 → 自己用词造句 → 观察两个细节 → 词块排序 → 自己扩句 → 自己写小作文 → 读一遍修改。奖励与宠物约1分钟；保留切换余量。15分钟计时包含路线和宠物页面；达到上限仍可保存，不新增任务奖励。小屋额外设90秒上限，不增加总预算。

## 已实现
六个主题区域、30个学习日节点；一屏一道题；30道原创语义辨析和对应排序练习；明确理由的对错反馈；错误无扣分；实际作答后按1/3/7/14日安排复习；复习只使用本人曾作答记录；错后答对不标为独立掌握。
三种原创矢量伙伴；孵化、五阶段外观变化；换围巾、喂饼干、击掌、小床和热气球布置；动画不发学习货币；每日有上限、无衰减惩罚。
四项原创表达沿用原有奖励流水；重复点击不重复发奖；保存孩子原文与修改稿；支持1.4备份恢复到1.5；保留家长密码、语音和可选云设置。

## 教学边界
当前是二年级通用起步课程；三至六年级设置调整写作提示，不等同于完整分年级题库。开放表达只做完成条件检查，绝不宣称机器已经准确判定其质量。
当前没有配置家庭Cloudflare授权，因此联网AI和跨设备云服务没有上线；本地提示始终标注不是AI批改。

## 未来课程优先级（尚未声称交付）
- 根据孩子真实错误设计第二轮迁移题，而不是无限增加关卡。
- 教师审核扩充三至六年级分层课程与每月同题对比。
- 导入实际学校单元和作文字段，不默认假设教材版本。

## 验收
检查实际Android安装/启动/存储与浏览器交互，不把设计稿当成App截图。Debug测试版签名；本版独立应用IDcom.wordpet.adventure，可与1.4并存，通过家长导出/导入备份转移作品，不能自动读取另一个应用的私有数据。
