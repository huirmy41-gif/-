# 作文小作家 · 星语岛 1.5

安卓手机和平板安装APK后即可使用，不用注册、配置服务器或购买服务。

点“开始我的小冒险”：每次只看一道题，先选词、说句子、观察、拼句，再独立写小作文。答错有解释，不扣星星。下次会复习需要巩固的内容。

完成一个真实表达任务后可以孵化云朵狗、棉花兔或星星龙。学习星星兑换围巾、饼干、小床或热气球，兑换和使用会改变小屋。伙伴不生病，不因休息惩罚。小屋互动每天最多90秒，包含在15分钟总预算里。

家长首次进入面板设置自己的6位密码。语音输入默认关闭；开启后使用设备的系统识别服务，可能联网，识别文字须本人确认。

本版以com.wordpet.adventure安装，与旧版com.wordpet.family并存。旧版有作文时，不要卸载：先在旧版家长页导出JSON备份，再在新版家长页导入。未配置云服务，本机数据不会自动跨设备同步。

本地提示不是联网AI批改。三至六年级设置调整提示，完整高年级题库尚未交付。所有测试结果见VERIFICATION.md，真实设备语音质量还需在你的设备验证。
