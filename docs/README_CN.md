# 家庭使用说明

## 安装后
打开“作文小作家·家庭版”，点“开始今天的小冒险”。不用填写服务器网址，也不需要付费。
第一次进入家长面板时由家长设置6位数字密码。它是防误操作的儿童隔离门，不是企业身份系统。

## 每天的练习
词语造句、观察两个细节、句子扩写、迷你作文。孩子先输入自己的内容，再点完成。每关1星，四关额外2星。
学习和宠物页面计时；进入后台暂停。15分钟到时暂停新任务，但允许保存，避免丢失文字。
新的一天自动重置任务，保留作品和星星。休息日不扣星、不让宠物生病。

## 作品与宠物
每次输入自动存稿。保存作品后保留原文，修改稿另存；重复保存和换伙伴不增加奖励。
宠物进化依据练习天数、作品数、修改记录，不宣称等于已掌握某项能力。礼物固定价，不抽奖不充值。

## 语音
家长独立授权系统语音输入。设备提供商可能联网处理声音；Word Pet不保存原始录音。
转写必须先确认才加入作文。朗读只选择设备已有的离线中文语音；缺少语音包会提示。

## 备份
家长面板导出JSON文件到自选位置；换手机、卸载或更新不同签名测试版前先备份。
导入会明确确认，保留恢复前快照。旧版兼容的JSON作品可导入。旧版与新版应用标识不同，不自动跨应用读取数据。

## 云与AI
不是必须配置。云端接口使用版本比较写入，冲突拒绝覆盖。本机数据不自动上传。
AI仅发送本次作文，默认关闭，最多1600字，家庭每日最多10次；本地提示不是AI。
没有Cloudflare授权和免费方案确认时，构建只报告缺项，不上线、不购买服务。
