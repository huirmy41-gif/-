# 作文小作家 Word Pet 1.4 家庭测试版

安装 APK 即可离线完成学习，不需要 Replit、服务器、账号或 API 密钥。
内置30个通用主题、四项写作练习、每日约15分钟、草稿自动保存、原文与修改记录、词语积累、宠物选择孵化、固定价格衣食住行礼物、家长密码、系统语音和文件备份。
应用标识 com.wordpet.family，与旧测试容器并存，不覆盖旧版作品。

## 下载
请从本仓库 Releases 下载实际 APK。下载名为 WordPet-Family-1.4.0.apk。
GitHub Actions 使用标准公共仓库 Ubuntu 运行器，不启用 Replit 付费部署。
这是侧载用 Debug 家庭测试版，不是应用商店正式版。不是全部联网功能已上线。

## 功能边界
联网AI和云同步可选、默认关闭。实际部署情况见随包 cloud-status.json；缺少账户授权时不部署、不收费。
内置老师是明确标注的规则提示，不冒充大模型批改。AI需要可用的家庭服务。
2至6年级提供递进的通用练习要求，不等于已经导入学校真实教材或验证教学效果。
语音能力取决于设备的中文语音包和系统识别服务，语音服务可能联网。
不要卸载仍有未备份作品的旧版。换设备或换签名测试版本前先备份。

## 隐私
不要在这个公开仓库提交真实儿童作文、备份、API令牌、配对密钥或签名私钥。
默认所有学习数据都留在应用私有存储。家长明确授权后才发送本次作文或手动同步快照。
