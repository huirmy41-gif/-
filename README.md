# 作文小作家 Word Pet 1.5 · 星语岛

面向小学二年级的写作练习与轻宠物养成。安装已发布APK即可离线学习，无需Replit、账号或家庭服务器。

## 本次重构
- 六个主题区域、30个学习日节点，显示当前路径，不要求一天走完。
- 一屏一步：词语辨义、自己造句、观察细节、词块排序、独立扩句、原创小作文、自己读一遍修改。
- 即时解释对错；实际答题记录驱动间隔复习。答错不扣生命、星星或宠物健康。
- 三种原创矢量伙伴，孵化与阶段成长；围巾换装、喂饼干、击掌、小床及热气球布置。
- 宠物互动上限90秒，纳入每日15分钟总预算；不设置充值、抽奖、广告、排行榜或断签清零。
- 原文和修改记录保留；星星流水防重复领取；家长密码、备份恢复、系统语音沿用。

学习节奏参考公开的路径式教学和间隔复习方法。角色、插画、题目及文案为Word Pet原创，不使用Duolingo品牌或课程素材。

## 下载与验收
从本仓库Releases下载实际发布的 `WordPet-Adventure-1.5.0.apk`。只有通过逻辑、浏览器交互、Android安装启动及存储测试的构建才会发布；具体数量和边界见该版本 `VERIFICATION.md`。

1.5应用标识为 `com.wordpet.adventure`，与1.4的 `com.wordpet.family` 并存。不要卸载仍有作品的旧版：在旧版家长页导出JSON备份，再在新版导入。

这是侧载用Debug家庭测试版，不是应用商店正式版；不同签名不能直接覆盖升级，换版前须备份。

## 功能边界
- 目前是二年级通用起步课程。三至六年级设置调整写作提示，不等同完整分年级课程。
- 本地提示明确标注为规则提示，不冒充大模型批改；本次改版不部署云服务、不启用付费套餐。
- 联网AI和跨设备同步需要另行完成家庭服务授权。当前离线使用不需要这些配置。
- 语音取决于系统中文语音包和识别服务；系统识别可能联网，需家长明确授权并确认转写。
- 星星、答题正确率和进化阶段不是经验证的作文能力评分；真实教学效果还需儿童实际使用验证。

请勿向公开仓库提交儿童真实作文、备份、访问密钥、API令牌或签名私钥。
